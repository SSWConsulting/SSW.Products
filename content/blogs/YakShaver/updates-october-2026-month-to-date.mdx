Across five releases published from 7 to 19 October, YakShaver improved how generated work fits your project, added a Zendesk destination, and made portal management clearer. This update covers product changes included in releases published between **1 and 22 October 2026, Australia/Brisbane**.

## YakShaver - 4 New Features

### Work items fit Azure DevOps and GitHub projects

YakShaver Anywhere now uses Azure DevOps work item fields and GitHub issue templates when preparing generated work. It can place details such as acceptance criteria into the destination's supported fields, and resolve supported @mentions against project or tenant users. For example, a GitHub issue can follow its repository's bug template, while an Azure DevOps item can use the project's acceptance-criteria field. Fields that a destination does not support can fall back to the description.

### Zendesk tickets can be routed and classified

The v0.96.0 release adds Zendesk as a destination for YakShaver Anywhere. A project can route a generated ticket to a Zendesk group, include recording context, and set ticket type, priority and supported account-specific dropdown fields.

### Manage links, widgets and shave history in the portal

You can rename project links and widgets in place, see clearer navigation and filter state, and get more reliable recording playback. Shave records also show where they came from, such as a link or widget. These are targeted portal improvements, making it easier to manage a project and understand the source of a report.

### Find widget setup from the Projects list

Project admins can see and sort widget counts, filter the Projects list to projects with YakShaver Widgets, and jump to widget setup. This view is for project admins.

## A couple of useful fixes

YakShaver Anywhere added silence and speech detection to filter transcript segments that do not contain speech. This helps keep words generated from silence or sounds such as ringtones out of a work item. The 19 October release also extends speech filtering to recordings processed through Teams, OneDrive and the browser extension.

A recorder fix also prevents a screen-share recording that contains audio from being incorrectly labelled “This recording has no audio”.

## October releases

* **v0.95.4 — 7 October:** Portal improvements and transcription filtering.
* **v0.96.0 — 19 October:** Structured work items, Zendesk, widget administration, attribution and recording fixes.
* **v0.96.1, v0.96.2 and v0.96.3 — 19 October:** Maintenance releases.
