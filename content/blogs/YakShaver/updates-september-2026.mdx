Over the last month, the YakShaver team shipped 15 new releases. The biggest changes make it easier to send a report, share a YakShaver Anywhere link, and see what's happening while a report is recorded or processed.

## Send a report where it needs to go

YakShaver can now send a work item to an email address, alongside its existing destinations. Setting up a GitHub project is easier too: if the connected GitHub app can access a repository, you can find it in a searchable list instead of pasting its URL.

## YakShaver Anywhere

Create a project link or QR code and share it with reporters. They can open it on a phone and record a shave with their camera, or upload a video from their device.

The link page is now available in Chinese.

## Know what's happening during a report

The browser recorder warns people when a recording has no audio and shows an error if processing fails, rather than a false success message.

On iOS, the embed widget offers video upload when the browser can't record the screen directly.

Reports keep processing if someone closes the tab. If their live connection drops, the page explains that the report is still underway, helping avoid a duplicate submission. The status page also tells reporters where to look for the result.

## A few more useful changes

The Integrations page is easier to scan on an iPad. Connection status is more accurate, project links are easier to read, and reporters can add a GitHub handle so issues can mention them.

## The releases, in order

* **v0.90.1 — 26 August:** Email reporting updates.
* **v0.91.0 — 31 August:** Email became an end-to-end work-item destination.
* **v0.91.1 — 1 September:** Fixed a blank screen when starting a browser report from the dashboard.
* **v0.92.0 — 7 September:** Added a searchable GitHub repository picker, clearer project links, and recording audio and status fixes.
* **v0.93.0 — 10 September:** Improved the Integrations page, connection status and recording warnings.
* **v0.94.0 — 14 September:** Added YakShaver Anywhere links and QR-code reporting, with retry and navigation fixes.
* **v0.94.1 — 16 September:** Reports keep processing if the reporter closes the browser tab.
* **v0.94.2 — 16 September:** Clearer feedback when a live connection drops, plus a fix for recording preview playback.
* **v0.94.3 — 17 September:** Clearer report status, reporter attribution and interrupted-processing messages.
* **v0.94.4 — 17 September:** GitHub issues can mention reporters who add their GitHub handle.
* **v0.94.5 — 17 September:** Maintenance release.
* **v0.95.0 — 21 September:** Added iOS video upload to the widget and improved embeds.
* **v0.95.1 — 22 September:** Added Chinese-language support to YakShaver Anywhere links.
* **v0.95.2 — 24 September:** Maintenance release.
* **v0.95.3 — 24 September:** Maintenance release.
