Fifteen releases went out between August 25 and September 25. The headline changes: email as a work-item destination, YakShaver Anywhere links and QR codes, a better path for iOS video reports, and a report flow that keeps going if the browser connection drops. Here's the release-by-release catch-up.

## More ways to get a report to the right place

### Email and GitHub setup

YakShaver can now send a work item by email as well as through its existing destinations. The release also improved the setup flow for GitHub repositories, replacing the guesswork of pasting a URL with a searchable picker when the connected GitHub app can see the repository.

### YakShaver Anywhere gets a link and QR code

YakShaver Anywhere now has a link-and-QR option. Share a project link or put its QR code on a sign; someone can open it on a phone and record with the camera or upload a video. The link page later gained Chinese-language support, so the reporter can switch languages without losing an in-progress recording.

## Recording that doesn't leave people guessing

The browser recorder now catches missing-audio problems and avoids showing a green success state when processing has actually failed. The embed widget also gives iOS users a video-upload option when their browser cannot record the screen directly.
Processing is less fragile too. Closing the tab no longer stops a shave that is already processing. If the reporter's live connection drops, the page explains that the report is still underway instead of inviting a risky second submission. The link page's interrupted state now uses a clear hourglass and points reporters towards where the result will appear when a destination is available.

## The smaller improvements add up

The Integrations page is easier to scan on an iPad, connection status better reflects what is actually connected, and project links use readable slugs. Reporters can add a GitHub handle for attribution, and the link page's status screens are easier to read. The link page also gained Chinese-language support.
