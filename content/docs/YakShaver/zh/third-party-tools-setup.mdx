YakShaver 与 [Microsoft Teams](recording-work-item-teams) 配合使用效果最佳，但你也可以使用任何你喜欢的录制应用。

## 操作步骤：

1\. 打开你使用的录制软件

2\. 如有需要，可在网上搜索**如何更改该工具的保存或输出位置**。

1. 将该工具设置为把录制内容保存到 OneDrive 中此文件夹内的任意位置：

`OneDrive → Recordings → {{ ANY FOLDER NAME }}`

1. 完成！保存录制内容时，YakShaver 现在会在视频保存后自动检测到它。

## 提示

* 带有键盘快捷键的工具可以帮助高级用户加快操作速度
* 只要文件最终位于 Recordings 文件夹内，YakShaver 就会自动处理它

## 故障排除

### 常见问题

* **文件格式错误？**\
  确保录制工具保存为 .mp4 或 .mov 格式
* **文件保存到错误位置？**\
  仔细检查录制工具设置中的保存位置
