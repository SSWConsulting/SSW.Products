# Overview

EasyLeave is a module in TimePro that helps users manage their leave requests easily. It connects with Microsoft services like Graph API, Outlook, and optionally CRM, to automate leave approval, calendar events, and timesheet creation—reducing manual work and keeping everything in sync.

# Key Features

* **Leave Request Workflow:** Provides an intuitive interface for employees to submit leave requests.
* **Automatic Timesheet Creation:** Once a leave is approved, a timesheet entry is created automatically.
* **Optional CRM & Outlook Sync** If enabled, leave appointments are added to users’ CRM and Outlook calendars automatically.
* **User and Group Lookup via Graph API:** EasyLeave uses Microsoft Graph API to fetch user and group info for assigning leave and public holidays.
* **Public Holiday Management:** Easily create public holidays and apply them to groups. These holidays can also sync to CRM and timesheets.
* **Error Notifications:** If something goes wrong—like a sync or timesheet failure—an email alert will be sent to the configured error email.
